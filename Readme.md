# Child Malnutrition Risk Stratification System — India

**Dataset:** NFHS-5 (2019-21) | 707 Districts  
**Goal:** Classify districts as High/Medium/Low malnutrition risk using ML  
**Stack:** Python, Scikit-learn, XGBoost, SHAP, GeoPandas, FastAPI, Streamlit  
**Timeline:** 55 Days | Started: May 2026  

## Project Structure
- data/raw — original downloaded datasets
- data/processed — cleaned, merged datasets
- notebooks — Jupyter notebooks (one per phase)
- src — Python scripts
- outputs — charts, maps, exports
- models — saved ML models
- reports — final documentation
