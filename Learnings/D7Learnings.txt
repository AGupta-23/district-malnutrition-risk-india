The errors part — most important:
errors='coerce' means — if any value cannot be converted to a number, don't crash, just replace it with NaN silently.
Three options exist:

errors='coerce' → bad value becomes NaN ✅ we used this
errors='raise' → bad value crashes the code with error
errors='ignore' → bad value stays as original text


Why we used coerce: Jabalpur had one unreadable value. Without coerce the entire conversion would have crashed. Instead it silently became NaN and we caught it in the next line with isnull().sum().
